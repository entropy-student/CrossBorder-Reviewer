# Normalized Product Records

This directory is the destination for reviewed, canonical Product Master JSON
after `product-pipeline.mjs normalize`.

Generated normalized files are not a substitute for supplier evidence. Keep
`TEST_FIXTURE_ONLY` outputs clearly labelled and do not import them as formal
Pawfectly products. User-supplied `DRAFT` records may be written only through
the explicit local adapter after review. `--write --publish` is a separate
explicit request; missing inventory and logistics facts must remain unknown
even when a local preview publication is allowed.
